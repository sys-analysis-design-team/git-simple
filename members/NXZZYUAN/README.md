\# 我的 Git 学习笔记



\## 第一次 Git 实验总结



1\. `git add` 的作用是：

将工作区中准备提交的修改加入暂存区，让 Git 知道下一次 commit 要提交哪些内容。



2\. `git commit` 的作用是：

把暂存区中的内容保存为本地仓库的一次版本记录，并生成一个新的提交。



3\. 本次实验中 `git restore notes.md` 的作用是：

撤销 notes.md 在工作区中尚未提交的修改，使文件恢复到修改前的状态。本次实验中就是放弃临时追加的文字。



4\. `commit` 与 `push` 的区别是：

commit 是把修改保存到本地 Git 仓库；push 是把本地已经产生的 commit 上传到 GitHub 远程仓库。
